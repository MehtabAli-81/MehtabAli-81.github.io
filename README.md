# Software Quality Assurance (SQA) Engineer Portfolio

Welcome to my personal SQA engineering portfolio website! This repository contains the source code for my interactive, ATS-optimized portfolio designed to demonstrate manual and automated testing practices, test artifacts, and software validation methodologies.

## 🚀 Live Demo
🌐 **Portfolio Website:** [mehtabali-81.github.io](https://mehtabali-81.github.io)

---

## 🛠️ Technical Stack & Tools

* **Frontend Framework:** Next.js (Static Export Mode)
* **Styling & UI:** Tailwind CSS, Lucide Icons, Glassmorphism UI
* **Testing Frameworks:** Selenium WebDriver, TestNG, JUnit
* **Programming Languages:** Java, Python, TypeScript
* **Test Management & Tools:** Jira, Postman (API Testing), Git, GitHub Actions

---

## 📋 Core SQA Competencies

* **Manual Testing:** Test Plan Creation, Test Case Execution, Defect Reporting, Regression Testing
* **Automation Testing:** UI Test Automation using Selenium Java, Page Object Model (POM) Design Pattern
* **API Testing:** REST API Validation, Postman Collections, Response Verification
* **Agile SQA Operations:** Sprint Planning, Bug Lifecycle Management, Cross-functional Communication
